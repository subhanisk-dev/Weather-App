# SkyCast – Weather Dashboard

A modern responsive weather dashboard built with React, Vite,
Axios and OpenWeather API.

## Features
- Real-time weather
- City search
- Current location weather
- °C / °F conversion
- 5-day forecast
- Hourly forecast
- Temperature chart
- Favorite cities
- Recent searches
- Dark / light mode
- Weather-based backgrounds
- Responsive design
- API error handling

## Tech Stack
- React
- Vite
- JavaScript
- CSS
- Axios
- OpenWeather API

## Setup
npm install

Create .env:

VITE_OPENWEATHER_API_KEY=your_api_key

npm run dev
